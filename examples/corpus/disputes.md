# Disputes

*Invented sample text for the quickstart corpus, not a real dispute policy.*

A dispute arrives from the card network with a reason code and a deadline. The
deadline is set by the network and is not negotiable, so an unanswered dispute
is a lost dispute.

Evidence is submitted once. There is no second submission, which is why the
console blocks the submit button until every required field for that reason
code is filled.

## Reason codes worth knowing

Code 10.4 covers a cardholder who does not recognise the charge. The usual
evidence is the delivery record plus the IP address at checkout.

Code 13.1 covers merchandise not received. A tracking number showing delivery
to the billing address answers it; one showing delivery anywhere else does not.
